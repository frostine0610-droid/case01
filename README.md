# CASE 01：消失的相机

一款基于 React 和 Vite 开发的校园日常推理网页游戏。玩家扮演摄影社社长兼手机机主林夏，解锁自己的手机，查看图库、微信、门锁、联系人和二手商品记录，通过跨应用核对还原相机失窃真相。

## 项目特点

- 五幕电影式案件引入，支持暂停、跳过和重播
- 模拟手机桌面、图库、微信、小程序、联系人和二手交易页面
- 关键线索按实际查看行为自动记录，不要求固定调查顺序，且不会提前显示总数
- 跨应用核对照片特征、门锁时间和脱敏手机尾号
- 积分线索提示、自动存档、错误答案定向提示
- 独立浏览记录：统计已打开的信息范围（包含干扰信息），但不影响结案
- 结案奖励、提交次数统计和 S/A/B 调查评级
- WebP 详情图与独立缩略图，降低图库加载体积

## 最终案件设定

摄影社公用相机在 9 月 18 日晚从 304 活动室丢失。20:20 的照片证明相机仍在器材柜中；方立声称自己早已离开，但门锁记录显示他直到 20:46 才离开。20:41 的走廊照片拍到其帆布袋中露出相机包特征。21:18，二手平台出现同一台相机，卖家联系尾号 7314 与通讯录中的方立号码尾号一致。

卖家昵称为“南屿”。完整手机号不会显示，玩家只能使用脱敏尾号完成身份核对。

## 游戏流程

```text
以林夏身份解锁手机
  → 五幕案件引入
  → 自由检查手机内容
  → 自动记录线索时间线
  → 可选积分提示
  → 收集全部关键线索
  → 提交三道调查结论
  → 结案报告、积分奖励与评级
```

玩家必须先收集全部关键线索，结论入口才会解锁。游戏不会提前显示线索总数；二手商品页的联系尾号与联系人中的相同尾号各自只算“半条线索”，两边都查看后才合并记录为一条完整线索。顶部“浏览记录”仅显示已打开的信息范围，包含干扰信息，不要求达到 100%；顶部 ↻ 按钮会在确认后清空本地进度并回到身份登录。

结案积分底层仍按以下方式计算：

```text
结案积分 = 时间基础奖励 × 线索完整度
```

线索完整度由“已收集关键线索 / 全部关键线索”计算；由于提交时必定已经收集完整，完整度系数恒为 1。玩家不能通过猜答案跳过调查，结案速度决定最终时间奖励档位。

调查评级同时考虑完成时间、报告提交次数和提示使用次数：一次提交、未使用提示且在 5 分钟内完成可获得 S；三次内提交且最多使用一次提示可获得 A；其他成功结案情况为 B。

## 技术栈

- React 18
- Vite
- 原生 CSS
- 浏览器 `localStorage` 存档
- Node.js 纯函数测试与 Playwright 浏览器完整通关测试

## 本地运行

需要 Node.js 20.19.0 以上版本；也支持 Node.js 22.12.0 以上版本。

```bash
npm ci
npm run dev
```

浏览器访问终端显示的本地地址。

## 构建与验证

```bash
npm test
npm run check
npm run build
npm audit
```

- `npm test`：依次执行规则测试与 Chrome 浏览器完整通关测试
- `npm run check`：依次执行代码规范、案件数据、全部测试和正式构建检查
- `npm run lint`：检查 JavaScript、JSX、测试与配置文件的代码规范
- `npm run validate:data`：检查 ID 引用、题目答案、时间线、评级和素材文件
- `npm run test:unit`：验证案件数据、存档清洗、判题、提示兑换和奖励边界
- `npm run test:e2e`：真实操作浏览器，覆盖半线索合并、线索集齐解锁和正确结案
- `npm run test:e2e:headed`：在可见浏览器中运行完整通关测试，便于观察和排错
- `npm run build`：生成生产文件到 `dist/`
- `npm audit`：检查依赖的已知安全问题

## 数据与文档约定

`gameData.json` 是程序运行时的唯一数据源。修改人物、文案、线索、题目或奖励时，应同步更新：

1. `gameData.json`
2. `案件.txt`
3. `证据设计.txt`
4. `scripts/walkthrough-test.mjs` 中对应断言

内部使用 E01—E08 作为稳定线索 ID，但玩家界面不显示这些编号。

## 存档说明

游戏进度保存在浏览器 `localStorage` 中，保存内容包括：

- 已发现线索
- 已查看内容
- 浏览记录
- 已兑换提示
- 积分
- 报告答案与提交次数
- 当前页面及结案状态

存档只用于本地单机体验，不包含账号或真实个人信息。登录页是剧情演出，不是真实身份认证系统。

## 素材处理

图库已经使用 WebP 详情图和 480px 缩略图。当前仓库只保留游戏实际使用的优化后素材；需要重新生成图片时，应从仓库外保存的原始素材重新导出。

## 已知限制

- 浏览器测试默认调用本机安装的 Google Chrome；运行环境需要提供 Chrome
- 浏览器测试同时覆盖正确通关、错误答案重交、损坏存档恢复，以及半线索提交门槛
- 游戏面向 PC Web，窄屏手机并非主要适配目标
- 所有案件数据与判题逻辑都在前端，适合课程作业和单机体验，不适合作为防作弊竞赛系统
- 手机解锁界面仅用于叙事沉浸，不执行真实认证，也不收集真实个人信息

## 设计文档

- `案件.txt`：案件真相、人物、时间线和范围限制
- `证据设计.txt`：手机应用、线索触发和验收标准
